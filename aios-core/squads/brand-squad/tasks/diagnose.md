# Task: diagnose (modo FAST)

## Objetivo

Diagnóstico rápido de posicionamento de marca para uso quando não há informação suficiente
(briefing incompleto, pesquisa inexistente, prazo curto) para acionar tasks mais profundas como
`define-brand-positioning` ou `create-brand-voice-guide`. Serve como triagem: identifica o
problema central de marca e recomenda o próximo passo certo, sem fingir profundidade que os dados
disponíveis não sustentam.

## Quando usar

- Cliente chega sem pesquisa de mercado, sem brand key, sem dado de concorrência.
- Pergunta aberta tipo "o que vocês acham da nossa marca?" sem escopo definido.
- Pré-venda ou primeira reunião, antes de aprovar um projeto completo de branding.

## Entregáveis esperados

- **Hipótese de Território Atual**: em 1 parágrafo, o que a marca parece estar tentando ocupar
  hoje (mesmo que de forma confusa ou implícita).
- **Sinais de Alerta**: lista de 3 a 6 sintomas observáveis (inconsistência de tom entre canais,
  ausência de diferenciação clara, concorrentes dizendo a mesma coisa, naming problemático etc).
- **Pergunta Crítica Não Respondida**: a 1 pergunta que, se respondida, mais reduziria a
  incerteza sobre o posicionamento.
- **Recomendação de Próximo Passo**: qual task/agente do squad deveria ser acionado a seguir, e
  por quê.

## Formato de saída esperado

```
## Diagnóstico Rápido de Marca

**Território atual (hipótese):** ...

**Sinais de alerta:**
- ...
- ...

**Pergunta crítica:** ...

**Próximo passo recomendado:** [task/agente] — porque ...
```
