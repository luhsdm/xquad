# Task: Design Landing Page

## Objetivo

Especificar o design completo de uma landing page a partir de um briefing de oferta, definindo a sequência de seções, a hierarquia visual de cada bloco e o padrão de leitura (F-pattern ou Z-pattern) mais adequado ao conteúdo, com foco em conversão e responsividade mobile-first.

## Entregáveis esperados

- Estrutura completa de seções (Hero, Prova Social, Oferta, FAQ, CTA, Rodapé e quaisquer seções adicionais necessárias ao briefing).
- Para cada seção: objetivo/objeção que resolve, elementos visuais principais, hierarquia entre eles e posicionamento de CTA (se houver).
- Indicação do padrão de leitura escolhido (F ou Z) e justificativa.
- Notas de responsividade: o que muda da versão mobile para a desktop.

## Formato de saída

```
## Especificação de Landing Page

Padrão de leitura: [F-pattern | Z-pattern] — Justificativa: ...

### Seção 1: Hero
- Objetivo/objeção resolvida: ...
- Elementos e hierarquia: ...
- Mobile vs Desktop: ...

### Seção 2: Prova Social
...

(repetir para cada seção até CTA final)
```
