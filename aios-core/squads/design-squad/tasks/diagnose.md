# Task: Diagnose (modo FAST)

## Objetivo

Diagnosticar rapidamente uma peça visual ou interface existente (anúncio, landing page, tela de produto, post de social media) e apontar os problemas concretos de hierarquia visual, usabilidade, consistência de marca ou conversão — sem propor redesenho completo nesta etapa. O foco é identificar o que está quebrando o resultado antes de qualquer retrabalho.

## Entregáveis esperados

- Lista priorizada de problemas encontrados, do mais crítico ao mais cosmético.
- Para cada problema: o que está errado, por que isso prejudica o resultado (conversão, usabilidade ou consistência de marca) e qual princípio/framework foi violado (ex: contraste WCAG, ponto focal único, hierarquia tipográfica).
- Indicação de qual agente do squad deveria conduzir o redesenho de cada problema identificado.

## Formato de saída

```
## Diagnóstico Rápido

1. [Problema crítico] — Por quê: ... | Princípio violado: ... | Agente responsável pelo fix: ...
2. [Problema secundário] — ...
...

## Resumo executivo
(2-3 frases sobre o estado geral da peça e a prioridade número 1 de correção)
```
