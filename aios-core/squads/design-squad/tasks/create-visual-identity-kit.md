# Task: Create Visual Identity Kit

## Objetivo

Criar um kit de identidade visual aplicada que sirva como referência reaplicável para qualquer peça futura da marca: paleta de cores com função definida, escala tipográfica, componentes base e guidelines de uso de logo e espaçamento.

## Entregáveis esperados

- Paleta de cores nomeada por função (primária, secundária, sucesso, alerta, neutra), com valores hex/RGB e contraste mínimo validado contra WCAG AA.
- Escala tipográfica modular (títulos, subtítulos, corpo, legenda) com fonte, peso e tamanho relativo.
- Lista de componentes base (botão, card, ícone) descritos como átomos/moléculas reaplicáveis.
- Guidelines de uso de logo: área de respiro mínima, variações permitidas (positiva, negativa, monocromática) e combinações proibidas.
- Grid de espaçamento (base 8pt ou 4pt) para margens e paddings.

## Formato de saída

```
## Kit de Identidade Visual

### Paleta
- Primária: #... — uso: ...
- Secundária: #... — uso: ...
- Sucesso/Alerta/Neutra: ...

### Tipografia
- Título: fonte, peso, tamanho
- Subtítulo / Corpo / Legenda: ...

### Componentes base
- Botão: ...
- Card: ...

### Guidelines de logo
- Área de respiro: ...
- Variações permitidas: ...
- Proibições: ...

### Grid de espaçamento
- Unidade base: 8pt | Múltiplos usados: ...
```
