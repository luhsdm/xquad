# Task: write-sales-page

## Objetivo

Criar uma página de vendas/carta de vendas completa a partir de um briefing/oferta validado, estruturada para conduzir o leitor cético até a decisão de compra.

## Pré-requisito

Rodar diagnose.md antes. Sem Big Idea definida e sem prova mínima identificada, a página não deve ser escrita — retornar perguntas ao cliente primeiro.

## Entregáveis esperados

- Big Idea explícita e ângulo (Reason Why + Mechanism) que sustentam a página.
- Texto completo estruturado em blocos: Headline, Lead, Big Idea, Corpo/Claims com prova, Bullets de benefício, Oferta, Garantia, CTA, P.S.
- Indicação do framework dominante usado (RMBC, PAS ou AIDA) e por que foi escolhido para este público/oferta.
- Nota de pontos onde prova adicional do cliente é necessária (se houver).

## Formato de saída

```
## Página de Vendas: [nome da oferta]

**Big Idea:** ...
**Framework dominante:** [RMBC | PAS | AIDA] — motivo: ...

### Headline
...

### Lead
...

### Corpo (Claims + Prova)
...

### Bullets de benefício
- ...

### Oferta
...

### Garantia
...

### CTA
...

### P.S.
...

**Provas pendentes do cliente:** [lista ou "nenhuma"]
```
