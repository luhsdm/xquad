# Task: Diagnose (modo FAST — fallback rápido)

## Objetivo

Produzir um diagnóstico executivo rápido de uma situação estratégica corporativa, acionando as cinco lentes C-level (CEO, CFO, CMO, COO, CTO/CPO) de forma resumida, quando não há tempo ou contexto para o fluxo completo de PRO (brief de decisão + outline de board).

## Quando usar

Quando o usuário traz uma pergunta estratégica de topo (aposta grande, alocação de capital, posicionamento competitivo, M&A, scaling, buy-vs-build) e precisa de uma leitura executiva imediata, sem todo o aparato de um brief formal ou apresentação de board.

## Entregáveis

- Leitura de 2-4 linhas por lente C-level relevante ao caso (não force as cinco lentes se não forem todas pertinentes).
- Um sinal de alerta crítico (red flag) por lente, se existir.
- Uma recomendação única e direta de próximo passo, com o C-level "dono" da decisão identificado.

## Formato de saída

```
## Diagnóstico Executivo Rápido

### [Lente CEO/CFO/CMO/COO/CTO]
- Leitura: ...
- Red flag (se houver): ...

### Recomendação
- Próximo passo: ...
- Dono da decisão: [C-level]
- Urgência: [alta/média/baixa]
```

Manter o diagnóstico em no máximo uma página. Não expandir para análise de cenários ou trade-offs detalhados — isso pertence à task executive-decision-brief.
