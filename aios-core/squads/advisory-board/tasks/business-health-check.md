# Task: business-health-check

## Objetivo

Aprofundar o diagnóstico rápido (diagnose.md) em uma avaliação estruturada de saúde de negócio, com cada conselheiro do squad contribuindo sua leitura específica e um indicador de severidade por dimensão. Esta task assume que já existe informação suficiente do negócio (coletada na fase diagnose ou fornecida pelo usuário) para ir além do sinal superficial.

## Entregáveis esperados

- Avaliação de saúde por dimensão (mercado, operações, pessoas/cultura, finanças/crescimento) com nível de severidade (saudável / atenção / crítico) e a justificativa baseada em framework específico de cada conselheiro (ex: Rule of 40 para finanças, Cinco Forças de Porter para mercado, RACI/Pareto para operações, eNPS/turnover para pessoas).
- Identificação de interdependências entre dimensões (ex: problema de cultura causando turnover que afeta operação, que afeta entrega ao mercado).
- Lista de riscos latentes (problemas que ainda não explodiram mas têm alta probabilidade de explodir se não tratados).

## Formato de saída esperado

```
## Business Health Check

### Mercado — [Saudável/Atenção/Crítico]
Framework usado: ...
Leitura: ...

### Operações — [Saudável/Atenção/Crítico]
Framework usado: ...
Leitura: ...

### Pessoas/Cultura — [Saudável/Atenção/Crítico]
Framework usado: ...
Leitura: ...

### Finanças/Crescimento — [Saudável/Atenção/Crítico]
Framework usado: ...
Leitura: ...

### Interdependências identificadas
- [dimensão A] impacta [dimensão B] porque ...

### Riscos latentes
- ...
```
