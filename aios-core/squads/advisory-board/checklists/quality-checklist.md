# Checklist de Qualidade — Diagnóstico Estratégico Generalista

- [ ] As quatro dimensões (mercado/competitividade, operações, pessoas/cultura, finanças/crescimento) foram endereçadas explicitamente, mesmo que com profundidade desigual quando a informação for limitada.
- [ ] Cada leitura por dimensão está ancorada em um framework nomeado (ex: Cinco Forças de Porter, Rule of 40, RACI, eNPS) e não em opinião genérica sem método.
- [ ] O diagnóstico identifica causa provável dos sintomas, não apenas lista os sintomas observados.
- [ ] Suposições assumidas por falta de informação estão declaradas explicitamente, não escondidas como fato.
- [ ] Existe ao menos uma recomendação imediata e acionável, executável sem depender de levantamento adicional.
- [ ] Iniciativas estratégicas (quando presentes) estão priorizadas por matriz de Impacto x Esforço, não apresentadas como lista plana sem ordem.
- [ ] O número de iniciativas estratégicas recomendadas simultaneamente é pequeno (no máximo três a cinco) — diagnóstico que recomenda tudo de uma vez não prioriza.
- [ ] Existe um próximo passo claro, concreto e atribuível (o quê, quem, quando) para a iniciativa de maior prioridade.
- [ ] Métricas de sucesso de cada iniciativa foram definidas antes da execução, não propostas a posteriori.
- [ ] Interdependências entre dimensões são consideradas (ex: problema de cultura afetando operação, problema de mercado afetando finanças) em vez de tratar cada dimensão isoladamente.
- [ ] Quando o diagnóstico revela um problema de domínio específico fora do escopo generalista, há sinalização explícita de encaminhamento para o squad especializado correspondente.
